# 2026-10-28 登录页表单位置配置（居左/居中/居右）

- 类别：任务
- 级别：L3（新增前端布局偏好取值域 `authFormPosition`，登录页布局与工作台布局相互独立）
- 关联：未提交

## 1. 内容留存

诉求：登录/注册页需要自己的布局配置——表单位置可选居左/居中/居右，默认居右。

实现：

1. `src/constants/theme.ts`：新增 `AUTH_FORM_POSITIONS`（left/center/right）、`AUTH_FORM_POSITION_LABELS`、`DEFAULT_AUTH_LAYOUT`（默认 `right`）。
2. `src/stores/theme.ts`：`ThemePrefs` 增加 `authFormPosition`，载入脏值校验回退默认，新增 `setAuthFormPosition`，
   `apply()` 写根节点 `data-auth-form-position`，`save()`/`reset()`/watch 同步持久化。
3. `src/views/LoginView.vue`：新增桌面断点（`min-width: 993px`）下的 `:global` 规则——
   `left` → `.auth-layout` 变 `row-reverse`（品牌区到右侧）；`center` → 品牌区 `position:absolute; inset:0`
   **全屏铺底**（保留渐变/网格纹理/光晕），`.auth-main` 透明并 `z-index:1` 承载浮层卡片，品牌内容收进左侧窄栏
   （`max-width: calc(50vw - 290px)`，按卡片左沿反算避免重叠）、卖点列表隐藏、slogan 用 `clamp()` 随视口缩放；
   `right` 为默认 flex 顺序。窄屏（<993px）不参与切换，品牌区仍为顶部横幅。
4. `src/components/ThemeDrawer.vue`：登录路由下新增「登录页布局」区块（表单位置三段控件），
   与工作台的「布局配置」「交互偏好」互斥显示；抽屉副标题与恢复默认文案同步。
5. `AGENTS.md` 前端结构条与项目记忆同步：两套布局相互独立、`data-auth-form-position` 消费方、仅桌面生效。

后续迭代（同日）：布局配置改为**可视化缩略图卡片**，登录页与工作台同步处理。
`ThemeDrawer.vue` 中以 `.viz-card`（缩略图 + 文案）替换 `seg` 分段控件，缩略图全部用 CSS 方块拼出、不引入图片/图标资源：

- 表单位置：品牌块 + 表单块，`row-reverse` / 隐藏品牌块并居中 / 默认右；
- 导航布局：侧边竖条 vs 顶部横条 + 内容行；
- 内容宽度：内容块 62% 居中收窄 vs 100% 撑满；
- 界面密度：行高 2/4/6px + 间距 3/4/5px 三档示意。
选中态沿用强调色描边 + `@c-accent-soft` 浅底，与外观模式卡片一致；`box-sizing: border-box` 显式声明（仓库无全局 reset）。
按用户选择追加「方式 1」：缩略图外框加细网格底纹（两条 `linear-gradient` + `background-size: 9px 9px`，
线色 `color-mix(in srgb, var(--app-line) 42%, transparent)`），版式蓝图感更强，区域块之间的留白处透出格线。

再次迭代：登录/注册页整页无滚动条。
`.auth-layout` 由 `min-height:100vh` 改为 `height:100vh/100dvh + overflow:hidden`；
`.auth-main` 补 `box-sizing:border-box`（仓库无全局 reset，原 padding 会把高度撑出 100vh 形成滚动条）
并改为 `overflow-y:auto` + `scrollbar-width:none` + `::-webkit-scrollbar{display:none}`：
视口过矮时只在表单区内部滚动且不显示滚动条，页面级永远无滚动条。

## 4. 未验证项与风险（可选）

- 桌面端「居中」浮层已在 1024×619 视口实测通过；「居左/居右」两档未在同一桌面视口逐一截图复核（规则同源，仅换向）。
- 「居中」浮层在 993~1200px 区间品牌栏较窄（`calc(50vw - 290px)` 最小约 206px），slogan 已用 `clamp()` 缩放，
  建议人工在该区间复核排版是否可接受。
- 极矮视口下表单区内部滚动依赖 `scrollbar-width:none`（Firefox/Chromium 支持，旧 Safari 仍可能显示细滚动条）。
