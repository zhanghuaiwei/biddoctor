## 1. 内容留存

基于全量功能做前端封装层收敛，消解 17+ 视图中重复的分页/动作/标签/页头/下载样板。工作区存在并行会话持续演进（平台化 admin 视图、报告流、凭证上传等），本任务全部走 Edit 精确锚定迁移，与其改动无冲突合流。

**新增工具逻辑组件（composables/utils）**

- `src/composables/usePagedList.ts`：分页列表状态机唯一封装（items/total/page/pageSize/loading + reload/onPage），onMounted 自动首载，失败经 notifyApiError 统一提示；fetcher 闭包读筛选条件，可携带连带拉取（如用户页邀请码列表、告警页 unacked 聚合）。
- `src/composables/useApiAction.ts`：异步动作封装（按钮 pending + 统一错误提示），返回判别联合 `{ ok: true, data } | { ok: false }`——void 动作的成功/失败可区分（第一版 plain undefined 已修正）。
- `src/utils/download.ts::saveBlob`：Blob 落盘唯一实现（createObjectURL + a[download] + revoke），替换 3 处复制粘贴（LogsPanel/Stats 导出、订单凭证下载）。
- `src/utils/format.ts` 增补 `formatPercent`（0~1→整数百分比，空值 '—'）与 `formatLocaleNum`（zh-CN 千分位），替换监控大盘本地 pct/fmtNum。
- `src/constants/enums.ts` 新增 `USER_ROLES/USER_ROLE_LABELS/USER_ROLE_TAGS` 注册（消除 AdminUsersView 角色内联三元，展示层标签归口注册表）。

**新增视图组件（components）**

- `EnumTag.vue`：枚举状态标签统一渲染（labels/tags 引 enums 注册表，未知取值回退原码 + info；dot/plain 形态），替换 9 处 el-tag + 断言样板。
- `PageHeader.vue`：页头统一承载（eyebrow/title/desc + actions 插槽），替换 9 处 .page-head 手写结构。
- `ListPager.vue`：分页条统一承载（默认管理端常显口径，hide-single 单页隐藏，layout 可覆盖）。
- `src/styles/global.less` 收口共享工具类：`.pager/.panel-tools/.mt/.cell-id/.cell-strong/.cell-muted/.cell-mono`，删除各视图 scoped 重复定义。

**迁移接入（13 个文件）**：ProjectsView、QuotaView（含订阅计划/凭证上传新逻辑一并收口）、admin/{Users,Orders,Tasks,Notices,Alerts,Dicts,Configs,Jobs,Stats,Dashboard}View、components/admin/LogsPanel。

**刻意未迁移**：并行会话正在新建/重写的视图（AdminOrgs/Roles/Rules/Subs/Ai/Legal/Attachments、ReportDetailView、AgreementGate、NoticeBanner）——封装已可用，待其稳定后由后续任务增量接入，避免正面冲突。
