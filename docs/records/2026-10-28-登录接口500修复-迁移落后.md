## 1. 内容留存

现象：`POST /api/auth/login` 返回 500 `Internal Server Error`（带合法验证码时）。

定位：直接调用 `auth_svc.login` 打印堆栈，得到
`sqlalchemy.exc.ProgrammingError: (psycopg.errors.UndefinedColumn) column users.org_id does not exist`，
SQL 为 `SELECT ... users.org_id, users.invited_by ... FROM users WHERE email=...`。

根因：开发库 alembic 版本停在 `0001`，而 `app/models/` 已含平台化 v2.0 扩展列（`users.org_id`、`users.invited_by` 等），
迁移 `0002` 未执行 → ORM 查询列不存在 → 未捕获异常被统一异常层落成 500 纯文本。

修复：对开发库执行 `uv run alembic upgrade head`（0001 → 0002）。
代码侧无需改动：`README` 快速启动已要求 `bootstrap.py`（含迁移），属环境未同步。

验证：`POST /api/auth/login` 返回 200 与 JWT + user；随后软删诊断过程中创建的测试账号。
