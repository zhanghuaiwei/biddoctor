# 2026-10-28 二次确认弹窗样式修复（ElMessageBox 缺样式）

- 类别：任务
- 级别：L2（前端样式缺失 bugfix，影响全站 confirmAction）
- 关联：未提交

## 1. 内容留存

现象：项目详情页点「生成废标条款清单」，确认弹窗退化为左上角裸文本——无背景、无遮罩、无居中，
文字与页面内容重叠（用户截图可见）。

定位：`utils/confirm.ts` 通过 `ElMessageBox` 命令式调用，未经过模板；`unplugin-auto-import` 的
`ElementPlusResolver` 只注入函数而不带样式，`main.ts` 也从未显式引入 message-box / message 样式，
因此 `.el-message-box`、`.el-overlay` 等基础规则全部缺失。

修复：

1. `main.ts` 显式引入编程式 API 样式（放在 `global.less` 之前，保证后续覆盖生效）：
   `element-plus/es/components/message/style/css`（ElMessage 提示）、
   `element-plus/es/components/message-box/style/css`（确认弹窗，内部已链式引入 base/input/button/overlay）。
2. `styles/global.less` 增加 `.el-message-box` 产品化收敛：圆角 `@radius-lg`、`@c-line-soft` 描边、
   `@c-surface` 背景、`@shadow-lg` 阴影，标题/正文改用 `@fs-h3`/`@fs-sm` 与 `@c-text`/`@c-text-sub`，
   暗色下随 `--el-*` 变量自动切换。

影响面：全站所有 `confirmAction` 二次确认（退出登录、删除项目、发起对照、下单等）与 `ElMessage` 提示一并恢复为 Element 标准样式。
