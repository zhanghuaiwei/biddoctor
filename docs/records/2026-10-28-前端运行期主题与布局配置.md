## 1. 内容留存

按用户诉求完成前端产品化与运行时外观/布局配置，最终收敛为「登录页只配外观、工作台配外观 + 布局 + 交互」两套作用域：

1. **运行期主题**：`stores/theme.ts` 管理亮/暗/跟随系统（含系统变化监听）、5 套品牌预设色 + 自定义取色器，实时计算色阶写回 `--app-*` 与 `--el-*` 变量，localStorage 持久化并在 `main.ts` 启动前应用防闪白。
2. **布局偏好**（工作台专属）：新增 `navLayout`（侧边栏/顶部导航）、`pageWidth`（标准/全宽）、`density`（紧凑/标准/宽松），经 `data-nav-layout`/`data-page-width`/`data-density` 由 `global.less` 与 `MainLayout` 消费；`MainLayout` 支持顶部导航模式（横排品牌 + 水平菜单，侧栏模式保留面包屑）。
3. **交互偏好**（工作台专属）：弹层承载形态（按内容自动/强制弹窗/强制抽屉）、抽屉宽度、遮罩点击关闭、ESC 关闭。
4. **作用域拆分**：`ThemeDrawer.vue` 按路由 `isLogin` 判定，登录/注册页只保留「外观模式 + 主题色」；布局配置与交互偏好为工作台专属；移除原「效果预览」静态区块。
5. **反哺**：`AGENTS.md` 前端结构条补充运行期外观、布局偏好 `data-*` 消费（仅工作台）、登录页作用域、二次确认与统一弹层规则。

实际改动（文件级）：
